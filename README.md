# 口袋钓鱼 · Cardputer ADV

Pip-Boy 启发的磷光绿水域终端：废土水岸、目标追踪和标本档案，随时拿起来钓一会儿。没有角色或小猫。独立离线固件，通过已有 M5Launcher 安装。

当前是 **0.2.0 可安装原型**：物品扩到 24 类轮廓，加入互相关联的“听潮”档案，带轻微异常与深水未知气氛。沿用 v0.1.2 的自动跟鱼与空格收放线。用户已反馈早期版本好玩、A/D 操作困难；新版本的真机手感、档案小字可读性、续航与 SD 重启保留仍待实际确认。电脑验证结果见 [验证记录](docs/VALIDATION.md)。

0.1.1 是视觉更新：黑底磷光绿、FISH / LOG / SYS 标签、分段仪表与标本扫描框。扫描纹理静态放在内容后方，不闪烁、不盖住文字。原来的八种配色参数保留，在终端上转换成八档绿色明暗；名称、外观编号、生成算法和存档格式沿用 v1。

## 怎么玩

1. 空格抛竿。浮漂的小幅晃动是试探，先别提竿。
2. 浮漂下沉、出现“咬钩了”后，再按空格提竿。太早或太晚都会跑鱼。
3. 控制区自动跟随小鱼，不必来回找 A / D。仍可用 A / D 或逗号 / 斜杠手动微调；手动输入时暂时覆盖助力。
4. 按住空格收线，鱼冲刺或张力快满时松手。跟随区从鱼类 ±0.14 放宽为 ±0.18，提竿窗口增加 0.3 秒。助力不是自动收线，持续按住仍会断线。
5. 收线进度满才钓获。张力满会断线，长时间不收线会脱钩。

大鱼收线张力更高；外观编号决定缓游、急转、摆尾、冲刺四种基础习性。它们仍需真人调手感，自动控制器成功不代表难度恰当。

| 键 | 操作 |
| --- | --- |
| 空格 / Enter | 抛竿、提竿；遛鱼时按住收线；结果页再钓 |
| A / D 或逗号 / 斜杠 | 可选手动微调；图鉴选择标本；档案前后翻页 |
| R | 捕获页或图鉴读档案；再次按下返回原页。档案内空格 / Enter 循环翻三页 |
| B | 打开/关闭图鉴（岸边、结果页可用） |
| H | 查看帮助；游戏时间冻结，返回后继续 |
| P | 暂停/继续等待和遛鱼 |
| 1 / 2 / 3 | 岸边或结果页切换苇岸、暮湾、星潭 |
| M | 开关提示音，启动时默认静音 |
| Backspace / 反引号 | 退出图鉴、返回岸边；钓鱼途中放弃当前一竿 |

没有体力、签到、每日任务或离线惩罚。空闲一分钟会降低背光；游戏没有实现深度睡眠，不承诺待机续航。

## 程序生成与图鉴

鱼没有一张写死的完成清单。当前生成器把这些**实际参与绘制**的参数组合起来，鱼的规则继续与 v1 相同：

- 8 种体型 × 4 种尾鳍 × 4 种背鳍 × 8 种配色 × 8 种花纹 × 4 种面部 × 4 种装饰 = **131,072 种外观参数组合**。
- 物品使用 24 种轮廓 × 8 种配色 × 4 种表面状态 = **768 种外观参数组合**。新增瓶盖、录音带、工牌、怀表、听筒、手镜、手铃、骰子、照片、印章、药盒、罗盘、面罩、收音机、量尺、铅封。
- 单次抛竿的物品概率仍约九分之一；物品外观在 768 个编号中等概率抽取。旧物仍可钓到，每个旧编号不因扩容而改变含义。
- 不同钓点倾向不同颜色，所有钓点保留完整组合空间。灯、飘带、小冠出现概率不同。
- 个体尺寸独立生成，体型决定尺寸范围。大一点、换了随机种子、换了钓点，都不会被计为新外观。

这个数字是组合空间，**不是无限内容，也不是这么多个手工设计物种**。小屏上某些组合可能相似；没有声称全部图像逐一唯一。惊喜目前来自轮廓、花纹、稀有装饰与偶遇物品，实际是否持久有趣仍要试玩。

图鉴只显示已经保存的发现，不显示“总共还差多少”。每种外观保留第一次记录中的尺寸；后续同外观的渔获照常追加到日志，但不增加发现数。暂不做最大尺寸纪录页、升级装备、经济系统和物品用途。

## 废土档案

Pip-Boy 风格之外，这版补充了**原创废土小世界**，保持黑色幽默，借用异常留存档案与轻微宇宙恐怖的气氛。不是 Fallout / SCP 官方设定或原文，不出现正式 SCP 编号或怪物百科。

- **48 份物品主档案**：原有 32 份旧物变体档案，加上 16 类新物品的主档案。新类型的四种表面共享主档案，表面观察不同。768 是外观组合数，不是独立故事篇数。
- 8 组鱼类报告，将现有体型放进净水厂、配给与变异生态的背景；花纹和装饰另有对应的观察短文。鱼的原名称、可见体型和编号保留。
- 物品档案分三页：鉴定记录、关联物证、入库附记。**24 份关联物证页**通过“另见”串起净水三号的听潮试验、额外班次、沈与家属、封井及后续余波。可以乱序读，不设置任务目标或解锁负担。
- 鱼类仍有水域抄录和特征观察。文本是有限的手写片段，组合依赖外观与首次保存的钓点，不会每次打开随机改写。它不是无限 AI 故事；不同标本会共享片段。

旧图鉴可直接读新增档案。文本放在固件 Flash，按需引用字符串，不给每次渔获增加存储字段、不调用网络或模型。操作和存档提示保持直接清楚。

## M5Launcher 安装

升级前，在电脑备份已有的 `/PocketFishing/catches-v1.pfj`，用于可能的回退。下载/复制 `dist/PocketFishing-ADV-v0.2.0.bin` 到你已有的 FAT32 SD 卡，例如 `/Games/`，从 M5Launcher 的 SD 浏览器选中它安装。

- 这是 **ESP32-S3 应用镜像**，没有拼接 bootloader 或分区表；Launcher 把它装进应用分区。
- 游戏不需要额外资源包或数据分区。所需分区以安装器显示的实际大小为准。
- 本项目没有刷写设备、挂载或修改用户 SD 卡，也没有改动 Launcher。若安装器要求重分区，先停在该界面核对现有固件/数据，不能从 SD 容量推断 Flash 可用空间。
- 关机/重启后按你当前 Launcher 的方式返回启动菜单；游戏不直接改写启动分区，避免依赖未知 Launcher 布局。

官方依据：[Cardputer ADV](https://docs.m5stack.com/en/core/Cardputer-Adv)、[M5Cardputer](https://github.com/m5stack/M5Cardputer)、[Launcher 应用镜像格式](https://github.com/bmorcelli/Launcher/wiki/Explaining-the-project)。安装流程具体菜单取决于设备已有的 Launcher 版本，未在当前设备上实测。

## 存档与空间

存档在 SD 卡 `/PocketFishing/catches-v1.pfj`，每次成功渔获追加 **32 字节**。一万次渔获的日志为 320,000 字节；不含 FAT 文件系统分配开销。外观由编号重建，不逐条保存图片。

没有 SD 卡时可以试钓，显示“本局不存档”；重新开机不会保留该局渔获，也不会假装已经写入图鉴。图鉴只收录可读、已校验的磁盘记录。

每条日志包含魔数、顺序号、外观编号、随机种子、毫米尺寸、钓点、生成器版本和 CRC32。写后关闭重开，检查长度与内容一致才显示“已保存”。这仍不能保证廉价 SD 控制器在突然断电时已经物理落盘。

v0.2.0 可以混合读取生成器 v1 与 v2 的记录。旧记录原样保留，扩展物品使用原 256 个编号之后的新空间，新渔获标为生成器 v2；旧鱼规则和旧物编号含义不变。无需迁移或清空。

**回退边界：v0.1.2 及更早固件不认识 v2 记录，会在首条 v2 记录处停止读取并显示只读，无法显示其后的渔获。** 如需回退，先保留完整新档，使用升级前备份的副本，不用旧固件继续同一份新档。当前导出工具支持两种版本；不要用旧工具把新记录当作损坏尾部丢掉。

发现损坏或半条记录时，保留有效前缀供查看，停止追加并显示只读；**不自动清空、截断或覆盖原档**。写入失败同样停止后续保存。出错后不要继续依赖这局的保存提示，先在电脑备份并检查。

电脑只读检查：

```sh
python3 tools/journal.py /path/to/catches-v1.pfj
python3 tools/journal.py /path/to/catches-v1.pfj --export /new/path/catches.json
```

如要提取有效前缀，`--recover-prefix /new/path/recovered.pfj` 只创建一个新文件，拒绝覆盖已有文件，输入档保持不变。它不会自动替换设备存档；输入损坏时退出码仍为 2，即使导出了前缀。使用前先备份原档。

RAM 使用两份约 16 KB 的发现位图和一份 64,800 字节帧缓冲，随收藏数量不增长。图鉴采用顺序扫描，收藏很多后启动/翻页可能变慢；这版没有索引缓存。字体只包含界面和故事需要的字，本版 1117 字符、约 31 KB；不运行 Wi-Fi、AI 或应用商店。

## 开发与验证

仓库目录、工具职责和本地 Git 流程见仓库根目录的 `docs/REPOSITORY.md`。开发依赖固定在 `requirements-dev.txt`；开发命令需在源码工程内执行，安装 ZIP 不包含整个源码仓库。

```sh
# 在本目录，首次在父目录创建独立工具环境
set -e
python3 -m venv ../.venv
../.venv/bin/python -m pip install -r requirements-dev.txt
mkdir -p build
../.venv/bin/python tools/make_font.py
sh tools/test.sh > build/test-results.txt
../.venv/bin/pio run > build/firmware-build.log 2>&1
../.venv/bin/python tools/previews.py
../.venv/bin/python tools/package.py
```

`include/font_data.h` 已生成并纳入源码，通常无需重新下载字体。若增加中文文案，再运行 `../.venv/bin/python tools/make_font.py`。字体来源 Noto Sans SC，SIL OFL 见 `docs/FONT-LICENSE.txt`；其源文件 SHA256 保存在生成头文件中。

`tools/test.sh` 用同一份 C++ 逻辑与绘图代码跑无界面测试，开启 AddressSanitizer / UndefinedBehaviorSanitizer；PPM/GIF 是真实绘图代码的电脑渲染，**不是 ADV 实拍**。尚未提供可交互桌面版。

## 第一次真机试玩

1. 确认显示方向、颜色和中文可读；H 打开帮助。
2. 只用空格钓一条：看到咬钩再提竿，按住收线、张力高时松手。
3. 在捕获页按 R 阅读，空格翻页、R 返回；图鉴选择旧标本后也试一次，确认仍停在同一标本。
4. 成功钓一条，确认“已保存”；打开图鉴，再重启确认记录仍在。
5. 比较提示音开启/关闭，确认 ES8311 音频工作；静音不影响视觉提示。

依据实际反馈继续调难度和文字可读性。编译成功不代表这些实机检查完成。
