# Radwater 余波 · 玩法与存档

**v0.4.2 / Cardputer ADV**。随手钓两竿，捞起一点净水三号的故事。离线固件，通过已有 M5Launcher 安装；没有角色、小猫、体力或签到。

v0.4.0 根据实际试玩调整，v0.4.1 统一为 Radwater 品牌；两版存档完全兼容。玩法包括：约两三秒的收线、16 种有独立故事的鱼、结果页短文、12 类随机事件。画面从单色终端改为沙黄、灰绿、锈色的废土水岸，档案使用稳定的浅色纸面。三个钓点分别呈现排水口、废弃码头和深水浮标。属于原创废土故事，不使用 Fallout / SCP 的原文或官方设定。

## 安装

将 `firmware/Radwater-ADV-v0.4.2.bin` 放入已有 FAT32 SD 卡（例如 `/Games/`），在已有 M5Launcher 中选中安装。这是 ESP32-S3 **app-only 镜像**，不含 bootloader、分区表，也不需要额外资源文件。

**升级前备份 `/PocketFishing/catches-v1.pfj`。本版的新记录使用生成器 v3；v0.3.0 及更早固件遇到第一条 v3 时会停止读取。** 如需回退，保留完整新档，使用升级前副本。不要用旧版修复工具处理新记录。

已有记录只读取、不迁移、不改写；收起到同种鱼下面的是图鉴显示，不是删除原始记录。首次成功钓获后才追加新版记录。项目没有操作用户设备、SD 卡或 Launcher。

## 先坐会儿

启动后，旧椅子用约 2.6 秒展开，视角落到座位。“坐会儿吧。”稍后淡出，操作提示短暂出现后也会收起。可以一直看水，没有计时结束、奖励或自动钓获。空格 / Enter 在动画任何阶段都直接抛竿；B、N、H、F、1/2/3 等现有快捷键也立即响应。打开图鉴再返回，不会重播开场。

H 随时查看全部操作；返回岸边或换钓点会短暂显示当前水域、钓法和操作提示。无 SD 或收藏保存异常仍常驻提示。原有 60 秒空闲调暗继续生效，按键恢复亮度。三处水域和已发现物证带来的岸边变化继续保留。v0.4.2 没有改动存档格式，与 v0.4.0 / v0.4.1 兼容。

## 怎么玩

1. 空格抛竿，等浮漂下沉，再按一次提竿。提前按不会跑鱼，但仍需要在咬钩后重新按下。
2. 按住空格收线。鱼挣扎时，**松一下，再按住**。普通与特殊鱼都只有一次短挣扎，不必左右追鱼。
3. 持续按住会断线；读懂提示、松手即可继续。咬钩时来不及操作会暂停等你，按 P 重新开始提竿窗口。收线中放下约二十秒也会暂停保留进度。
4. 出水页直接读三行短文；R 读完整档案，空格再钓。阅读没有倒计时或逐字动画。

| 按键 | 用途 |
| --- | --- |
| 空格 / Enter | 抛竿、提竿、按住收线、再钓；档案与手记下一页 |
| B | 收藏柜；再次按 B 返回水域 |
| A / D（逗号 / 斜杠） | 收藏选择、档案前后翻页；不参与收线 |
| R | 捕获页或收藏柜打开档案，再按返回；已读正文有未读批注时直接打开批注 |
| U | 收藏柜优先找未读批注，再找未读正文 |
| T | 档案、收藏或结果页跳到已经收藏的关联物品；可跳转时档案底栏会提示 |
| N | 岸边、结果或失败页打开手记：调查摘记、水域介绍、最近十二条事件；N 返回 |
| C | 岸边或收藏柜继续上次阅读的已保存条目及页码 |
| E | 本竿遇到水下敲门后，在结果页轻敲回应；也可忽略并再钓，无限时要求 |
| F | 岸边或结果页循环浅水 / 贴底 / 深水 |
| 1 / 2 / 3 | 岸边或结果页切换苇岸 / 暮湾 / 星潭 |
| P / H | 暂停 / 帮助；时间冻结 |
| M | 声音开关，默认静音；视觉提示完整 |
| Backspace / 反引号 | 返回；钓鱼途中放弃本竿 |

三种钓法仍各有倾向：浅水鱼多，贴底旧物多，深水事件稍多；收线时长接近。基础候选的十万种子物品比例分别约 6.2% / 29.8% / 11.2%，实际连续游戏还受防重复和事件影响，不是掉落承诺。钓法和短时效果只在本次开机保留。

## 鱼与故事

- **16 个鱼种、16 份独立主档案**：交班鱼、食堂团鱼、退潮长尾、锅炉河豚、电缆带鱼、门卫角鱼、单面扁鱼、值夜灯鱼，以及八种对应异常生态。每种有固定可辨认外观，尺寸仍随机。
- **16 份鱼类关联批注**：获得对应物品后增加第二页。重复钓到时能读到相关观察；其余鱼只保留一页主档案，不用花纹、地点凑满三页。
- **物品内容维持**：24 类、768 外观组合、48 份主档案、24 份物证页和 12 对物品关联批注；原三页正文没有改写。
- 图鉴中鱼按种类去重，物品仍按外观去重；尺寸不同不新增条目。已读状态按正文内容去重：旧八类物品区分四种表面故事，颜色不同不重复标未读。批注有独立阅读状态。
- 最近三次抛竿的同类鱼 / 同外观物品会降低重复机会；连续缺少新内容时，从有限候选中偏向未发现鱼种或物品类型。不会保证每几竿必定有新故事。
- 调查摘记只列已经获得的工牌、照片、怀表和铅封中的事实，不代替玩家解释真相。U 找未读、T 跳关联，便于接起碎片。

收集工牌后暮湾值班灯亮起；照片带来空椅子；齿轮对应苇岸滴水，铅封对应浮标上的封口细节。它们由已验证收藏重建，重启后仍可呈现；无 SD 或保存失败不伪造收藏解锁。

## 随机事件

共十二类：倒影迟到、仪表错时、明日报告、临时排水、鱼群交班、无人广播、水下敲门、失物认领、风起收据、旧灯复明、局部小雨、远处铃声。

每竿最多一次，触发后冷却三至五竿。怀表、录音带和失物认领事件须成功钓获对应渔获后才进入记录；环境事件在抛竿时记录。广播根据当时是否已有工牌 / 合照展示不同文本，旧记录保留当时版本。重启会重置事件冷却和临时效果。

- 临时排水：接下来三竿采用贴底候选倾向；原先就是贴底时不会继续叠加。
- 鱼群交班：接下来两竿等待时间乘以 0.55；按竿数消耗，暂停和读故事不消耗。
- 水下敲门：E 回应更新本条记录，不移除收藏、不要求限时选择。
- 其余是短小的视觉或文字插曲。部分插曲保留温暖、日常的观察；主线无需等待某个低概率事件才能阅读。

N 可回看最近十二条事件。可选择的回应仅在当次事件仍为当前一竿时有效，历史事件不重新触发操作。事件不会改变真实系统时间或保存提示。

## 存档与兼容

| 文件 | 含义 |
| --- | --- |
| `/PocketFishing/catches-v1.pfj` | 每次渔获追加 32 字节：编号、种子、尺寸、地点、生成器版本与 CRC；混合读取 v1/v2/v3 |
| `/PocketFishing/reading-v1.pfn` | 独立追加式手记，每次快照 96 字节：阅读状态、书签页码、最近十二条事件 |

生成器 v1/v2 的原始重放逻辑保留。新生成器 v3 将鱼的旧体型及装饰位映射到 16 种固定外观，物品规则保持。旧鱼的归类为 `body | ((ornament & 1) << 3)`；旧原始外观、尺寸和种子保留在日志中，显示时使用该鱼种的固定轮廓。每种鱼展示第一条保存记录的尺寸。收藏数量变小是按鱼种归档的结果。

两份日志独立校验长度、顺序、字段及 CRC，写后重新打开逐字节确认。缺 SD、部分写入、读取或写入失败都有独立状态；保留有效前缀并停止追加，不截断或覆盖文件。收藏可成功保存而手记失败，结果页会明确提示“收藏已存 手记未存”。手记读取失败时仍能用已验证前缀，当前修改仅留在内存。

C 只恢复已保存的图鉴条目；不会恢复关机前正在收线的进度。未安装 SD 时可玩、可看本次事件，但重启不保留。突然断电的物理落盘仍需真机验证。

电脑只读检查 / 导出：

```sh
python3 tools/journal.py /path/to/catches-v1.pfj
python3 tools/journal.py /path/to/catches-v1.pfj --export /new/path/catches.json
```

导出同时保留原始 `appearance_id` 与当前分组 `catalogue_id`。`--recover-prefix /new/path/recovered.pfj` 只创建新文件，拒绝覆盖，输入异常时仍返回退出码 2。旧工具不支持 v3，请使用本版工具。

收藏索引固定最多 784 项，启动扫描一次，之后翻页直接读取对应首条记录；不再为每次翻页重扫全档。内存不随钓获总次数增长。没有联网、在线 AI 或额外素材包。空闲一分钟降低背光，没有实现深度睡眠。
