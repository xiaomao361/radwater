# 听潮事件：作者用连续性说明

含剧透。此文件用于继续写作时保持一致，不在游戏内直接展示结局。

## 故事的确定部分

净水三号发现井水会提前复述人的声音。管理层把它当作节省通讯成本的技术，立项“听潮”。测深和人员定位出现无法用常规空间解释的结果；录音又把时间顺序打乱。项目以工牌姓名标记值班者，用交班铃转接岗位。

两次铃正常交班，第三次铃等待姓名。应答后，空岗位开始有人值守，但记录无法确认应答者、工牌持有人与真正到岗者是不是同一个人。额外的“十三班”没有进入正常时间表。沈进入这次事故，并试图用拆除传动齿轮停止试验；水泵停了，点名没有停。

防护措施转向“不回答”，声音却开始借用家属的身份。沈与家属之间留下通话、未寄家书、备用钥匙和孩子的玩具火箭。家属开过三号门，门禁与照片的人员数量互相对不上。休息室仍为某个值班者留着茶壶；共同梦境、汽水瓶和海螺表明异常没有被限制在井内。

留存科收集物证、制定临时规定。人事与管理层通过注销姓名、改写岗位和盖章，把失踪人员变成报表上的正常数据。最终铅封从井内闭合，交班铃暂时停止；至少有一个岗位仍被占据。新的采购与轮休安排继续执行，事故并没有因为结案而得到解释。

## 有意不确认的部分

- 井底是什么、它是否具有一个意志，不命名、不画出实体。
- 从三号门离开的是谁，是否有人主动留下，不用旁白替物证定案。
- 沈是否仍活着、镜中的人是谁，保留有限且可相互解释的线索。
- 记录中“已处理”“无人失踪”是机构的说法，不作为作者确认的事实。

未知来自声音、身份、空间、时间和记录间的小裂缝。没有等级体系、巨大怪物、血腥场面、邪教说明或正式 SCP 编号；“留存科”是本作原创机构称呼。

## 24 类物证的阅读线

玻璃瓶 → 量尺 → 罗盘 → 录音带 → 手铃 → 工牌 → 怀表 → 生锈齿轮 → 面罩 → 听筒 → 漂流信 → 印章 → 旧靴子 → 遗落钥匙 → 照片 → 玩具火箭 → 小茶壶 → 药盒 → 瓶盖 → 海螺 → 收音机 → 手镜 → 铅封 → 骰子 → 玻璃瓶。

这是一条互相引用的线索链，不是解锁顺序。任意物件可以先读；“另见”只给名称，不自动获得、解锁或标记未发现物件。每类的第二页承担它在整件事故中的位置，第一页面向这件物品自己的小故事，第三页提供表面观察与入库规定。鱼类与三处水域的旧报告是生态及日常侧证。

## 黑色幽默与连续性检查

- 笑点落在制度如何维持表面正常：异常声音不影响收费、额外员工不领工资、未知失踪不影响考勤。
- 每件物品须能独立读懂，不靠最后一句随机段子凑幽默；温柔的家属片段可由第二页的行政处理形成反差。
- 公文允许矛盾，但矛盾应指向同一事故或机构掩饰；避免作者把寄信者、人名、物件来源写错。
- 原有靴子、钥匙、家书、茶壶和玩具火箭继续属于沈与等待者的线索。保留已有主档案，新增关联页补足来龙去脉。
- 体型和编号是标本身份；故事补充身份，不把旧瓶子改成新录音带。换表面不凭空换一位主角，尺寸、随机种子不改写故事。
- 文本有限：32 份旧物变体主档案 + 16 份新类型主档案 = 48 份物品主档案；新类型的四种表面共享主档案，表面观察不同。另有 24 份关联物证页、8 组鱼类报告与 3 份水域记录。768 是外观组合，不是 768 篇独立故事。

本轮逐项核对了 24 个引用名称与可生成类型，自动检查引用链覆盖全部类型；人工核对了家书由沈书写、家属来电、门禁与照片人数差异等叙事关系。图连接检查不能替代玩家对整体故事与幽默效果的评价。

## v0.3.0：让物证相遇，让异常进入水面

三种异常只让玩家短暂看到时间、倒影或报告的裂缝，不确认井底实体：双重倒影、怀表的 25:13、录音带的“已于明日完成”。不篡改真实存档提示或用故障冒充叙事。

新增批注保留原文，单独作为第四页。12 对覆盖全部类型：工牌/照片、录音带/怀表、手铃/面罩、玻璃瓶/量尺、罗盘/齿轮、听筒/海螺、家书/钥匙、玩具火箭/茶壶、印章/旧靴、药盒/收音机、手镜/铅封、瓶盖/骰子。是否读到由已保存物证决定，不靠开机次数或随机改写。

批注提供新的联系，不替玩家宣布真相。合照里留出的空位、同一晚修补的火箭与茶壶、镜面与铅封的对应痕迹，都延续原有事件；官僚话术继续承担黑色幽默。浅水、贴底和深水只改变体验节奏与掉落倾向，不另开三条互相冲突的故事时间线。


## v0.4.0 水边来信：鱼、事件与场景

玩家实玩后确认偏向休闲看故事：去掉组合数驱动的鱼图鉴，保留16份独立鱼主档案和16份物品关联批注。物品原有正文保持。鱼把停工后的日常留在水里：交班、食堂、测量、门卫、照路和归航；异常变种通过回声、十三班、镜像及内线与听潮相连。鱼不增加新的官方组织或明确怪物解释。

每种鱼的关联物品由 `fishEvidence` 明确列出；主档案不剧透关联批注，后者只在对应物品成功保存后出现。主线物品的24页闭环和12对批注保持原文。16种是有限物种，不声称有无限故事。

十二类事件文本在 `src/events.cpp`。广播按发生时持有的工牌/合照变化，并在手记中冻结当时语境；敲门的轻敲回应只更新记录，不新增惩罚或强制任务。风起收据延续家书中的两份晚饭，旧灯与飞虫保留日常温度。怀表、磁带、认领单必须真实钓获后才能记录，避免把尚未发生的结果写成事实。

长期场景变化从已验证收藏派生：工牌→暮湾值班灯、照片→空椅子、齿轮→苇岸滴水、铅封→深水浮标封口。只改变局部细节，不宣布结局。临时排水与鱼群交班使用剩余竿数，阅读不会耗尽机会。

画风经用户修正为整体废土气氛，不强制哔哔小子：灰绿水、沙黄色天空、锈色设施、纸面档案；不要全屏绿色扫描仪和反复故障闪烁。所有叙事保持原创，不借用官方台词。结尾依然允许未知，但让人可以安心暂时留在岸上。
