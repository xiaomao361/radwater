- 提早按键不丢鱼、持续持键不会自动提竿；未及时提竿进入暂停，P恢复提竿窗口；收线中离开会保留进度暂停。修复了验证发现的恢复后立即再次暂停问题。

## 自动化

命令：`sh tools/test.sh`。同一份设备 C++ 核心/渲染代码，开启 AddressSanitizer、UndefinedBehaviorSanitizer、`-Wall -Wextra -Werror`。实际输出见 `../build/test-results.txt`（本地生成文件，不是预置结论）。

- 100,000 个生成样本：确定性、外观编号范围、尺寸范围、所有特征取值可达、记录编码回读/校验。
- 不输入、始终按住、过早提竿、不收线、过度收线都不会自动成功；暂停与帮助冻结时间。
- 300 个固定种子由跟随/松线控制器完成。它检验可解性，不证明真人难度、按键响应或乐趣。
- 存档首次发现去重不受尺寸变化影响；鱼与物品命名空间分离；重启回读、SD 缺失、短写、磁盘拒绝写、损坏和有效前缀只读。
- 标准库 Python CLI 自动检查导出/恢复到新文件、保留损坏输入、拒绝覆盖已有输出；损坏输入不会因恢复前缀成功而退出 0。
- 256 份渲染样本检查视觉哈希多样性；静态截图和样本图人工查看。没有遍历证明 131,072 张图全都唯一。

命令：`../.venv/bin/pio run`。固定 espressif32 6.10.0、M5Cardputer 1.1.1、M5Unified 0.2.21、M5GFX 0.2.28。实际内存、文件大小与 SHA256 在 `../dist/manifest.json`。

源码核对：M5Cardputer 1.1.1 能按 ADV 选择 TCA8418 键盘驱动；其 KeysState 使用 `del`，不是上游 master 新增的 `backspace`。编译时发现版本 API 差异，已按实际锁定版本修正，并检查本文件用到的其他键值接口。M5Unified 的 ADV SD 引脚与本项目 40/39/14/12 一致。

交付镜像检查：esptool `--chip esp32s3 image_info` 返回 Checksum valid、Validation Hash valid；打包器核对 ESP32-S3 芯片 ID、应用大小和 ZIP 内逐文件字节一致。
